## CNN 모델 변천사

### AlexNet 2012

- 5개의 합성곱 계층, 3개의 완전연결 계층
- 출력 해상도 = ((w - k + 2p) / s) + 1
- 출력 활성 메모리 = C * H' + H'
- 파라미터수 k = 출력 채널 수 * 입력 채널 수 * k**2(필터 웨이트) + 출력 채널 

### VGGNet 2014

- 5개의 합성곱 블록 + 맥스풀링 구
- 작고 단순한 필터를 깊게 쌓으면 성능 증가

### ResNet 2015

- 잔차블록 사용
- stem 구조 사용

### MobileNet

- 목표: 모바일/임베디드 환경에서 구동

#### 모델 상수 초기화

- 학습률 코사인 변경
- 학습률 선형 변경
- 역제곱 꼴, 일정갑 유지

빠른 종료

### 하이퍼파라미터 값 조정

랜덤 탐색, 그리드 탐색

직관으로

#### 직관

1. 초기손실값 확인(log(C))
2. 과적합 시켜보기
    - 손실 안줄면
        - 학습률, 초기화 무제
        - 모델 구조 오류 가능성
        - 활성화 함수 이슈
        - 코드 버그, 최적화 툴 이슈
    - 손실이 폭발할 때
        - 학습률 줄이기, 초기화 변경
        - 네트워크 깊거나, 구조적 이슈
3. 학습률을 찾기
    - 100 iteration동안 학습률 우선 탐색
4. 후보 학습률 + 후보 가중치 변형 방식 중 좋은 조합 탐색
    - 1-5에폭동안 모델 학습시켜 성능 비교
5. 10-20 에폭까지 추가학습
6. 학습률에 따른 손실곡선 관찰
    - 손실의 이동평균 관찰
    - 학습 데이터, 검증 데이터 모두 확인

##### 학습률에 따른 손실곡선 관찰
- 초반 손실값 유지: 초기값 문제
- 손실 유지: 학습률 변경(줄이기) 시도
- 학습률 변경 적용 후 학습 진행 x -> 너무 일찍 학습률 줄임

##### 학습률에 따른 정확도 곡선

- 정확도 증가시: 계속 학습
- 학습/검증 정확도가 크게 벌어진 경우: 과적합
- 학습/검증 차이 적으면: 모델 힘 약한 것
