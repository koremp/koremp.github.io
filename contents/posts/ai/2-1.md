## Attention

- Seq2Seq의 한계인 병목 문제(Bottleneck problem) 해결 위해 등장
- 동적 Context Vector
- BLEU Score
- 장점
  - 해석가능성, 정렬
- Query, Key, Value
- score 계산 -> softmax -> 가중합 -> 단어 예측

## Self Attention

- RNN 대신 Self Attention으로 해결
- RNN 한계
    - 장기 의존성
    - 병렬화

- Query, Key, Value

- Self Attention 한계
  - 순서 정보 부재
    - 포지셔널 인코딩
  - 비선형성 부족
    - feed forward network
  - 미래 참조 문제
    - masked self attention
